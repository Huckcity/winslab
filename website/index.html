Quick Start

  1. Launch Winslab and create a workspace from WinsLab > New.
  2. Add cues from the toolbar: Audio, Group, Fade, Wait, Stop, or More for MIDI / OSC / Network / Script.
  3. For audio, drag files directly into the cue list to auto-create cues.
  4. Select a cue to edit it in the Inspector panel.
  5. Press GO to run the selected cue and advance through your show.

Transport and Hotkeys

GO

Runs the selected cue. Advances selection according to timing and cue rules.

STOP

Stops selected running cue context, depending on cue type and runtime state.

PANIC

Immediate safety action. Stops all audio and clears active playback quickly.
